The box model: my answers

1. Which element is the parent panel?
 <div> is the parent panel.

2. Which CSS rule controls the space inside the panel border?
  Padding is the CSS rule that controls the space inside the panel borders.

3. Which CSS rule controls the space after each panel?
Margin is the CSS rule that controls the space after each panel.

4. Why does the image use `width: 100%`?
The image uses 'width: 100%' because to make it fill up the full width of its parent container, allowing it to fit the panel without overflowing.

 5. Why can both panels use the same CSS?
 Both panels can use the same CSS because they share the same class name and design, also don't need to repeat the code because one CSS rule can style both panel consistently.
