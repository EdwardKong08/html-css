CSS foundations: my answers
 1. Which line in `index.html` connects the CSS file?
The <link> tag in the <head> section of index.html connects the CSS file.

 2. In `body { background-color: #ecfdf5; }`, what is the selector?
 The selector is body.

 3. In that same rule, what is the property and what is the value?
Property is background-color,while Value is #ecfdf5

4. Why does `.resource-card` start with a dot in CSS?
The dot (.) indicates that .resource-card is a class selector in CSS.

 5. What is the difference between padding and margin in the resource card?
 Padding is the space inside the resource card, between the content and the border, while margin is the space outside the resource card, between the card and other elements.

 6. Which selector, property and value did you change in "Make one small change", and what changed on the page?
I changed the background-color property in the body selector to #ecfdf5, which changed the page background to light green.
