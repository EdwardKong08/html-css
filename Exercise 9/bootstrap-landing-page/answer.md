Bootstrap landing page: My answers
## 1. Which Bootstrap classes did you use for the navbar?
I use navbar, navbar-expand-lg, navbar-dark, container, navbar-brand and navbar-nav.

## 2. Which value on the navbar button points to the menu?
I use data-bs-target="#mainMenu" to connect the button to the menu.

## 3. Which grid classes changed the layout of the hero section?
I use row, col-md-6 and align-items-center. It makes two columns on big screens and one column on small screens.

## 4. Which card classes did you use?
I use card, card-body, card-title, card-text and h-100.

## 5. Which styles did you put in custom.css, and not as Bootstrap utility classes in the HTML?
I use custom CSS for background colors, text colors, card design, hover effects, border radius, navbar color and form input colors. These make my website look different and special.
