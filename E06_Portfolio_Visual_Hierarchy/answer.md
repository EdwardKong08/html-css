 Portfolio visual hierarchy: my answers

## 1. Which CSS rule makes the strongest text on your page?
font-weight: bold;

## 2. Which CSS rule makes the paragraph text easier to read?
line-height: 1.6;

## 3. Which color did you use for actions or emphasis?
A bright accent color, such as blue.

## 4. Which spacing choice separates one content group from another?
margin

## 5. What becomes more difficult to read quickly if each text element has the same size and color?
It become harder to see which information is important and find things quickly.
