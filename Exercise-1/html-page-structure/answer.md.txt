 1. What is the job of the `head`?
 The job of the <head> element in HTML is to act as a container for metadata (data about the document).

  2. What is the job of the `body`?
  The main job of the <body> element in HTML is to hold and display all the visible and interactive 
  content of a web page that users see in their browser.

 3.Why does `<title>` change the browser tab, and not the visible page?
  The <title> element changes the browser tab rather than the visible page because it lives inside the HTML <head> section, 
  which stores behind-the-scenes metadata about the document rather than visual content.

4. When must you use `<ol>`, and not `<ul>`?
Use <ol> when items follow a strict sequence, ranking, or progression,
Use <ul> when the items are a collection of equals and rearranging them does not change the meaning.

5. Why must an image have useful alt text?
An image must have useful alt text (alternative text) for several key reasons:Accessibility for Screen Readers,
Fallback for Broken Images and Cognitive and Learning Support

6. What connects a `<label>` to an `<input>`?
A <label> connects to an <input> using the for attribute on the label and the matching id attribute on the input, 
or by nesting the <input> directly inside the <label>.
