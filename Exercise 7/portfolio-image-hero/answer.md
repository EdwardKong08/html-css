 Portfolio image hero: my answers

## 1. Which image goes in the HTML, and why?
The workshop-desk.png image goes in the HTML because it is important content and shows my workspace.

## 2. Which image goes in the CSS, and why?
The workshop-background.png image goes in the CSS because it is used as a decorative background.

## 3. Which CSS property stops the content image from stretching?
The object-fit: cover property stops the content image from stretching and keeps its original ratio.

## 4. Which element makes the boundary for the positioned label?
The .image-panel element with position: relative makes the boundary for the positioned label (.image-label).

## 5. What did you do to keep the text easy to read?
I used a dark overlay on the background image and light-colored text to make the text easier to read.
