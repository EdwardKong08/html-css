Image positioning: my answers

## 1. When must an image go in the HTML, with `<img>`?
Use <img> when the picture is important for the website content.

## 2. When must an image go in the CSS, with `background-image`?
Use it for background patterns, textures and decorative images.

## 3. What does `object-fit: cover` do?
object-fit: cover makes the image fill the container completely.

## 4. Why does `.photo-panel` need `position: relative`?
.photo-panel needs position: relative to control the position of elements inside it.

## 5. What makes the text easy to read on top of the background image?
Use a dark overlay on the background image to make the text more visible.

## 6. Which change did you make? What changed in the browser, and which CSS property caused it?
I changed the colors, width, height, padding and border radius. The website looks wider, cleaner and more modern. The CSS properties that caused these changes are background-color, color, max-width, min-height, height, padding and border-radius.
